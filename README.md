# 📈 Monitor de Cotação do Dólar via Telegram

Aplicação em Python desenvolvida para monitorar a cotação do Dólar em tempo real através da API AwesomeAPI e enviar alertas automáticos para o Telegram sempre que o valor atingir a meta configurada.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Requests** (Consumo de APIs REST)
- **Python-dotenv** (Gestão de variáveis de ambiente e segurança)
- **Telegram Bot API** (Notificações em tempo real)
